# Pantry Dash 🧀

A cat-and-mouse chase game that runs in any browser, on phones and computers.

You are Pip the mouse. Eat every cheese crumb in the maze while the cats chase you.

- **Chili**: scares the cats for a few seconds, so you can chase them back to their basket.
- **Bonus treats**: strawberry, donut, cupcake, watermelon and golden cheese pop up twice per level. Grab them before they vanish.
- **5 rooms**: The Kitchen, The Pantry, The Dining Room, The Bakery and The Midnight Fridge. A second cat joins from level 3.

## Controls

| Device   | Move                                   | Pause      |
|----------|----------------------------------------|------------|
| Computer | Arrow keys or W A S D                  | P or Esc   |
| Phone    | Swipe on the board, or tap the arrows  | ❚❚ button  |

## Play it online with GitHub Pages

1. Create a new **public** repository on GitHub, for example `pantry-dash`.
2. Click **Add file → Upload files** and upload `index.html` (and this README if you like). Click **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, pick the **main** branch and the **/ (root)** folder, then click **Save**.
5. Wait a minute or two, then refresh the page. GitHub shows your link:
   `https://YOUR-USERNAME.github.io/pantry-dash/`

Share that link and anyone can play, on any device.

**Tip for phones:** open the link, then use **Add to Home Screen** in your browser menu. The game opens like an app.

## Play offline

Just double-click `index.html` to open it in your browser. Everything is in that one file.
